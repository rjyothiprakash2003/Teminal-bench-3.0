This page is the authority for `/app/leasebox/leasebox.go` and `/app/conf/gate.ini`. Layout numbers, exit codes, and pool bounds come from `/app/spec/journal.rules`. Behavior not named here is outside the interface.

Drive. Build the package under `/app/leasebox` and run `leasebox <command> …`. When `LEASEBOX_RULES`, `LEASEBOX_CONF`, or `LEASEBOX_JOURNAL` is unset, use `/app/spec/journal.rules`, `/app/conf/gate.ini`, and `/app/var/journal.bin`. `LEASEBOX_NOW`, when set, is a signed Unix timestamp used for grant expiry, compact, list, and report and is not clamped; when unset, use the wall clock.

Record layout. Each stored record is exactly `RECORD_BYTES` long. The full `MAGIC` string occupies the leading bytes. `VERSION` and the active flag follow `MAGIC` and must not overwrite it. Name, owner, expiry, nonce, and CRC occupy the offsets and lengths named in the rules file. Expiry and nonce are unsigned big-endian integers of `EXPIRE_LEN` and `NONCE_LEN` bytes. The checksum is IEEE CRC32 of the bytes before `CRC_OFF`, stored as that integer in `CRC_LEN` big-endian bytes.

Gate. `/app/conf/gate.ini` carries `MAX_LEASES` and `TTL_SEC`. Both must sit inside the rules `MAX_LEASES_MIN`/`MAX_LEASES_MAX` and `TTL_MIN`/`TTL_MAX` bands. Gate integers are signed decimal values (an optional leading '+' or '-' is allowed; leading zeros are decimal, not octal). When a selected gate is outside those bands, `grant` exits 1 and leaves the journal unchanged (no new record).

Live lease. A record is still-live when its active flag is set and its expiry is strictly greater than the clock. Expired uncompacted records and inactive records are not still-live.

Grant. `grant NAME OWNER` appends one active record when admission succeeds. Names match on the stored `NAME_LEN` prefix. The owner argument is stored as its `OWNER_LEN` byte prefix (longer owners are truncated into the field; shorter ones are zero-padded). A second grant of a still-live name exits `EXIT_DUP` with no extra active record. `grant` admits at most `MAX_LEASES` still-live leases and exits `EXIT_FULL` when that cap is already full, including after a later legal `LEASEBOX_CONF` lowers the cap, with no extra active record. When a grant is both a duplicate and would exceed `MAX_LEASES`, including after the cap is lowered below current occupancy, exit `EXIT_DUP`. Expired uncompacted records do not count toward the cap. When `LEASEBOX_NOW` plus `TTL_SEC` is negative or exceeds the unsigned `EXPIRE_LEN`-byte maximum, grant stores that signed sum converted to an unsigned `EXPIRE_LEN`-byte value by modular wrap into the field width. Each successful grant stores a distinct nonce in the selected `NONCE_LEN` encoding, including after `compact` and after `revoke`, even when the same name is granted again. When every unsigned `NONCE_LEN`-byte value has already been issued, `grant` exits 1 with no extra active record.

Revoke. `revoke NAME OWNER` removes every stored record whose stored `NAME_LEN` prefix matches the revoke argument, including when several records share that prefix, and leaves unrelated names in place. When no stored name matches the revoke argument's `NAME_LEN` prefix, revoke exits 0 and leaves the journal unchanged.

Compact. `compact` drops every record whose expiry is less than or equal to the clock and keeps all other stored records, including inactive records whose expiry is still greater than the clock. Nonces on those kept inactive records remain issued.

List. `list` prints JSON even when empty, and null, an empty array, or an empty object is allowed. A nonempty list is valid JSON that includes every still-live name as a name field on an object, as a leases or items array of those objects, or as a name-keyed object; it lists only still-live leases, so expired uncompacted rows are omitted.

Verify. `verify` exits 0 on a clean journal, including empty, missing, or zero-byte, `EXIT_CRC` on a CRC mismatch in any record, and `EXIT_CRC` when the file length is not a multiple of `RECORD_BYTES`.

Report. `report` writes `/app/out/lease-report.json` with `magic` set to the `MAGIC` string and with `records` and `active` as JSON integers that may be zero: `records` is stored rows and `active` is still-live leases. When that path already exists as a non-regular file, report removes the obstacle and writes a regular file there within the command time limit rather than hanging or leaving the obstacle in place.
