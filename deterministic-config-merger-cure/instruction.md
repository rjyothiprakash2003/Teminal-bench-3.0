Write the layered configuration merger at `/app/merge.py` so that it does what `/app/docs/merge-contract.md` says; the file there now is a stub that always writes `{}`. The examples under `/app/examples` each hold a merge root with the output or refusal line the notes give for it; they illustrate the notes and are not used for marking.

Grading copies that one file alone and runs it with `python3 -I -S /app/merge.py --root <dir> --out <file>` as an unprivileged user, so only the standard library can be imported. Those runs use roots the shipped tree does not contain and that stay inside the bounds the notes state. Grading compares the bytes written to `<file>` on success, and the refusal line, exit status and untouched `<file>` on refusal. Each run may take at most 4 seconds.
