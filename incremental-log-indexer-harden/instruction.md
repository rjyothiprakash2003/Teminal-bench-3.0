Write the log indexer in `/app/logindex` so that it replays a journal from standard input and prints the answers that `/app/docs/indexing-notes.md` defines on standard output. The notes are the only authority for what the program does. The stub in that directory builds and prints a fixed line; replace it with a full program in Go that uses only the standard library. The journals and answers under `/app/examples` illustrate the notes and are not used for marking.

Grading copies `/app/logindex`, builds it there with `go build` from the Go 1.24 toolchain within 300 seconds, and then runs the built program once for each journal with no arguments. Every run must exit with status 0 and print exactly the bytes the notes define; standard error is not read. Each run may take at most 10 seconds. Every journal grading uses meets the domain the notes state.
